## 🏠 عن المشروع

**دارك (DARK)** هي منصة ويب سودانية مبتكرة تهدف إلى حل مشكلة عدم الثقة في سوق الإيجار السوداني من خلال:

- ✅ **التوثيق الميداني** لكل عقار بالصور والتحقق الفعلي
- 🔐 **التحقق من الملكية** والمرافق قبل النشر
- 🌍 **خدمة الجالية** السودانية في الخارج للإيجار عن بُعد بثقة
- 💬 **تواصل مباشر** عبر واتساب مع أصحاب العقارات

## 📊 حالة قاعدة البيانات

تم إنشاء قاعدة البيانات بنجاح! راجع [PROJECT_STRUCTURE.md](PROJECT_STRUCTURE.md) للتفاصيل الكاملة.

### إحصائيات سريعة:
- **19 جدول** تم إنشاؤها
- **6 مدن** سودانية مجهزة
- **7 أنواع** عقارات
- **12 مرفق** متاح
- **9 إعدادات** نظام أولية

## 🚀 البدء السريع

### المتطلبات الأساسية
- Python 3.x
- SQLite3

### التحقق من قاعدة البيانات
```bash
python3 backend/init_db.py
```

### الاستعلام المباشر
```bash
sqlite3 database/darq.db
```

## 🌐 تحسين الأداء للشبكات الضعيفة

تم تصميم DARK خصيصًا للعمل بكفاءة في ظل ظروف الشبكات الضعيفة في السودان:

### الميزات المتاحة:
- ✅ **Offline-First**: يعمل دون اتصال بالإنترنت
- ✅ **Service Worker**: تخزين ذكي للموارد
- ✅ **Lazy Loading**: تحميل الصور عند الحاجة فقط
- ✅ **Image Optimization**: صيغ WebP المضغوطة
- ✅ **Code Splitting**: تحميل الكود عند الطلب
- ✅ **IndexedDB**: تخزين البيانات محليًا
- ✅ **Queue & Sync**: مزامنة تلقائية عند عودة الاتصال
- ✅ **Network Detection**: كشف نوع الشبكة وتكييف المحتوى

### صفحات خاصة:
- [حالة الشبكة](assets/network-status.html) - عرض حالة الاتصال وجودة الشبكة
- [Service Worker](assets/js/service-worker.js) - إدارة التخزين المؤقت
